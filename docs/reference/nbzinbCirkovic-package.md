# nbzinbCirkovic: Negative Binomial and Zero-Inflated Negative Binomial Regression

Fits NB2 regression
([`nbreg()`](https://cirkovicdavid.github.io/nbzinbCirkovic/reference/nbreg.md))
by IRLS alternated with Newton-Raphson for \\\log\theta\\, and
zero-inflated NB regression
([`zinbreg()`](https://cirkovicdavid.github.io/nbzinbCirkovic/reference/zinbreg.md))
by an EM algorithm whose M-steps are IRLS fits. Standard S3 methods
(`summary`, `predict`, `residuals`, `logLik`, ...) are provided for
both.
